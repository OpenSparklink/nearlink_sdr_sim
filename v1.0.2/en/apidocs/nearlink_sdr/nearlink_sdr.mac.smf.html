nearlink_sdr.mac.smf¶

System management frame codec — TXS-10002-2025 standard 6.6

Implements complete encoding/decoding of System Management Frames:

  • SMFHeader: system management frame packet header (segmentation indication + signaling number)

  • ScheduleSignaling: 系统管理frame调度signaling (6.6.2.1)

  • LinkSignaling: linksignaling (6.6.2.2)

  • OffsetSignaling: offsetsignaling (6.6.2.3)

  • SystemManagementFrame: 完整系统管理frame组装与parse

nearlink_sdr.mac.smf.reassemble_smf(fragments: list[bytes]) → nearlink_sdr.mac.smf.SystemManagementFrame[source]¶

将segment的系统管理framedata重组为完整frame

每个 fragment 是一个完整的系统管理frame payload (含 SMFHeader)。 按照segmentindication规则:

  • FIRST(1): 首段, 取其 header 的signaling编号

  • MIDDLE(2): 中间段

  • LAST(3): 尾段

  • COMPLETE(0): 不segment, 直接parse
