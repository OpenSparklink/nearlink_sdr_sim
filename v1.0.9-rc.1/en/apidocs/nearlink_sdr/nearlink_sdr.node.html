nearlink_sdr.node¶

SLE node entity — unified TX/RX interface.

Integrates all MAC/PHY modules into a single SLE node, providing complete link lifecycle management and data TX/RX capability. Supports simulation mode and USRP hardware mode.

class nearlink_sdr.node.NodeConfig[source]¶

SLE node configuration.

Attributes: address: 6-byte device address. role: Role preference (AUTO/G_NODE/T_NODE). frame_type: Frame type (1-4). mcs_index: MCS index (0-12). bandwidth_mhz: Channel bandwidth (1/2/4 MHz). pilot_interval: Pilot insertion interval (0/4/8/16). max_pdu: Maximum PDU length (bytes). max_retransmit: Maximum retransmission count. enable_encryption: Whether to enable encryption. transport: Transport mode. band: Band identifier. hop_param2: Frequency-hopping parameter 2 (0 means auto-derived from address). blocked_channels: Set of blocked channel numbers. tx_power_dbm: Initial transmit power (dBm). max_power_dbm: Maximum transmit power. min_power_dbm: Minimum transmit power. channel_config: Channel model configuration for simulation mode (None for ideal channel). usrp_config: USRP hardware configuration (used when transport=USRP). smf_enabled: Whether to enable system management frame scheduling.

class nearlink_sdr.node.SleNode[source]¶

SparkLink SLE node entity.

Integrates link management, security, QoS, PHY pipeline, frequency hopping, power control, timing scheduling, access procedures, and channel model into a unified transceive interface.

usage::

node = SleNode(NodeConfig(address=b"\x01\x02\x03\x04\x05\x06"))
node.send(b"hello", Priority.NORMAL)
tx_result = node.transmit()
# ... 通过信道传输 tx_result.iq ...
rx_result = node.receive(rx_iq, n_bytes)
