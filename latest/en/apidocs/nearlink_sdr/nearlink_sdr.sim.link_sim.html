Throughput and frame error rate sweep across all MCS levels, with AMC envelope curve.

Iterate over all MCS indices (0-12); for each SNR point compute FER and effective throughput. Effective throughput = (1 - FER) * spectral_efficiency (bit/symbol). AMC strategy: select the MCS with the highest throughput at each SNR point.

Returns:

{ “snr_db”: […], “mcs_fer”: {mcs_idx: [fer_per_snr, …]}, “mcs_throughput”: {mcs_idx: [throughput_per_snr, …]}, “amc_throughput”: […], # AMC envelope throughput “amc_mcs”: […], # MCS index selected by AMC }
