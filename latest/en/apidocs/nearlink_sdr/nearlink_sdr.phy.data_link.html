nearlink_sdr.phy.data_link¶

Asynchronous/synchronous data link transmission procedure (standard 6.5.1 ~ 6.5.3).

Implements data link parameter management, flow control decisions, synchronous data discard mechanism, event group set scheduling, and segmentation/reassembly logic for synchronous service adaptation (periodic/aperiodic).

class nearlink_sdr.phy.data_link.AsyncFlowControl[source]¶

Asynchronous data link flow control decision (6.5.1.3).

Determine, per the standard rules, whether the initiator node should stop transmitting in subsequent events of the current event group.

should_stop_unicast_tx(tx_flow_ctrl: int, rx_flow_ctrl: int | None, rx_ack: bool | None, rx_data_len: int | None) → bool[source]¶

Unicast initiator stop condition (6.5.1.3).

Condition 1: Initiator sends flow_ctrl=0 and receives responder flow_ctrl=0, ACK, data_len=0. Condition 2: Initiator sent a message but received no responder message (rx parameter is None).

should_stop_multicast_semi_reliable(tx_flow_ctrl: int, any_nack: bool) → bool[source]¶

Semi-reliable multicast group leader stop condition.

Group leader sends flow=0 and receives no NACK.

should_stop_multicast_full(tx_flow_ctrl: int, member_feedbacks: list[tuple[int, bool, int]]) → bool[source]¶

Non-semi-reliable multicast / bidirectional multicast group leader stop condition.

Group leader sends flow=0, receives flow=0, ACK, data_len=0 from all members.

should_stop_feedback_multicast_leader(tx_flow_ctrl: int, member_feedbacks: list[tuple[int, bool, int]]) → bool[source]¶

Feedback multicast group leader stop condition, same as should_stop_multicast_full.

should_stop_feedback_multicast_member(prev_flow_ctrl: int, leader_ack: bool) → bool[source]¶

Feedback multicast group member stop condition.

Member sent flow=0 in the previous event, and received the group leader ACK=success in the current event.

class nearlink_sdr.phy.data_link.SyncFlowControl[source]¶

Synchronous data link flow control (6.5.2.3).

Essentially the same as asynchronous flow control logic, but in a synchronous link the initiator stops directly after meeting the stop condition, and the responder behavior is constrained by the total number of events within the event group.
