nearlink_sdr.mac.security_manager¶

Security procedure integration management — TXS-10002-2025 standard 9.2-9.4.

Integrates pairing signaling (security.py), cryptographic primitives (crypto.py), and the link manager into an end-to-end security procedure:

  • Pairing state machine (PairingManager): drives pairing signaling exchange and key negotiation

  • Frame crypto context (FrameCryptoContext): manage payload_count and AES-CCM encryption/decryption

  • ECDH key exchange (P-256): generate key pairs and shared keys

class nearlink_sdr.mac.security_manager.PairingManager[source]¶

Pairing procedure state machine (standard 9.2).

Drive the pairing signaling interaction between the G node and T node to complete:

  1. Pairing initiate/request/response

  2. ECDH public key exchange

  3. Mutual confirmation code verification

  4. Link key derivation

  5. Session key derivation

Attributes: is_g_node: Whether the local end is a G node. kdf_type: Key derivation function type. auth_method: Authentication method. max_key_length: Maximum key length (bytes).
