nearlink_sdr.mac.smf_scheduler¶

System management frame transmission scheduling — TXS-10002-2025 standard 6.6.3.

Implements system management frame self-scheduling logic:

  • 6.6.3.1.1 Schedule via access start: extract SMF configuration parameters from access basic information

  • 6.6.3.1.2 Start scheduling via broadcast: extract SMF configuration parameters from extended advertising frame

  • SMF periodic transmission plan

  • SMF frame construction (including schedule signaling + link signaling + offset signaling)

class nearlink_sdr.mac.smf_scheduler.SMFScheduleParams[source]¶

SMF full scheduling parameters, extracted from the access or broadcast process.

When started via access, these parameters come from the access basic information in the access request/response frame; when started via broadcast, they come from the start system management frame information in the extended advertising frame (7.1.4.7).

class nearlink_sdr.mac.smf_scheduler.SMFTransmitScheduler[source]¶

SMF transmit scheduler.

Manage the periodic transmission plan for SMF:

  1. Calculate the transmission time slot for each SMF based on parameters

  2. Rotate frequency points according to the frequency hopping table

  3. Build SMF frames containing schedule/link/offset signaling
