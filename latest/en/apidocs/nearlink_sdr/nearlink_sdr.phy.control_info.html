nearlink_sdr.phy.control_info¶

Physical layer control information — TXS-10002-2025 standard 6.4

A 组: 无线frame type 1 和 2, CRC12, 种子为syncsequence低 12 位。 B 组: 无线frame type 3 和 4, CRC24B, 种子 0x555555, CRC 与 LLID XOR。
