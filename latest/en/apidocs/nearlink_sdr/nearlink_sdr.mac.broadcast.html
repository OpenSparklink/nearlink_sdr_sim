nearlink_sdr.mac.broadcast¶

Broadcast frame codec — TXS-10002-2025 standard section 7.1.4

Implements frame structure codec required for SLE broadcasting, discovery, and access:

  • Generic broadcast frame structure (BroadcastFrame)

  • Extended advertising frame resource configuration information (ExtAdvResourceConfig)

  • Discovery access resource configuration information (DiscoveryAccessResourceConfig)

  • Access basic information (AccessBasicInfo)

  • Access request information (AccessRequestInfo)

  • Access response information (AccessResponseInfo)

  • System management frame startup information (SystemMgmtFrameInfo)

class nearlink_sdr.mac.broadcast.BroadcastFrame[source]¶

Broadcast frame general structure (7.1.4, Table 25)

Structure indication (5 bits) controls optional fields:

  • bit 0: local identifier present

  • bit 1: resolving key identifier present

  • bit 2: peer identifier present

  • bit 3: extended advertising frame resource configuration present

  • bit 4: data section present
