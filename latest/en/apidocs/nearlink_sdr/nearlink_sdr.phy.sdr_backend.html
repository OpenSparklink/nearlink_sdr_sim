nearlink_sdr.phy.sdr_backend¶

SDR hardware backend abstraction layer.

Defines a hardware-agnostic unified interface supporting three backends: UHD (USRP), pyadi-iio (PlutoSDR/ANTSDR), and Mock (no-hardware simulation). Any backend implementing the SDRDevice interface integrates with SLETransceiver.

class nearlink_sdr.phy.sdr_backend.SDRConfig[source]¶

SDR device configuration parameters (backend-agnostic).

Variables:

  • backend – Backend type (“uhd” / “pluto” / “mock”).

  • device_args – Device address parameter. UHD: e.g. “addr=192.168.10.2”; Pluto: e.g. “ip:192.168.2.1”.

  • channel_num – SLE RF channel number.

  • band – Band identifier (“2400” / “5100” / “5800”).

  • sample_rate_hz – Sample rate (Hz).

  • rx_gain_db – Receive gain (dB).

  • tx_gain_db – Transmit gain (dB).

  • bandwidth_hz – Front-end analogue filter bandwidth (Hz), 0 = auto.

  • rx_antenna – Receive antenna port name.

  • tx_antenna – Transmit antenna port name.

  • stream_timeout_s – Stream operation timeout (seconds).

  • rx_buffer_size – Receive buffer size (number of samples).
