nearlink_sdr.mac.qos¶

MAC layer quality of service management — TXS-10002-2025 standard 6.5/7.2

Implements data transmission quality control for asynchronous/synchronous data links:

  • ARQ automatic repeat request: sequence number management, ACK/NACK feedback, retransmission decision (6.5.1)

  • HARQ hybrid automatic repeat request: TB-based and CBG-based feedback modes (6.5.1.1)

  • Flow control: TX buffer management and flow control signaling (control info flow_ctrl field)

  • Link quality tracking: MCS feedback, FER estimation, AMC recommendation (control info LQI field)

  • TX queue: priority classification and PDU management

ARQ sequence number and retransmission state.

Asynchronous data link transmission process described in standard 6.5.1.1:

  • tx_sn: whenprevioustransmitsequencenumber

  • expected_rx_sn: Expected sequence number from the remote end

  • pending_ack: whenpreviouswait ACK dataisnonot yetacknowledgment

  • retransmit_count: Retransmission count of the current packet

  • max_retransmit: Maximum retransmission count (0 = unlimited, default for async links)
