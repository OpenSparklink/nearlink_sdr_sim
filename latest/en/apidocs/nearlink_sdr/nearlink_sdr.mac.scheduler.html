nearlink_sdr.mac.scheduler¶

Timing scheduler — TXS-10002-2025 standard 6.3/6.6/7.2.

Manages SLE system base slots, scheduling slots, superframe structure, and event group scheduling:

  • System base slot (Tsys = 125 μs, 30-bit counter)

  • System scheduling time slot (Tschedule = k x 25 us, k in {1,2,3,4,5})

  • Superframe: time resources between two adjacent SMFs

  • Event group: container for multiple events, repeating at the event group period

  • Time slice: scheduling time block within a superframe (offset + duration + period + repeat count)
