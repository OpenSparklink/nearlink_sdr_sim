nearlink_sdr.phy.usrp¶

USRP E310 hardware interface layer.

封装 UHD Python API, 提供针对 SparkLink SLE standard优化的 USRP device管理、 TX/RX 流interface以及与现有 PHY module的集成 Pipeline。

Hardware parameters (USRP E310 / AD9361):

  • Frequency range: 70 MHz - 6 GHz

  • Maximum bandwidth: 56 MHz

  • ADC/DAC: 12-bit

  • RX 增益范围: 0 - 76 dB

  • TX 增益范围: 0 - 89.75 dB

  • Antenna ports: TX/RX, RX2

class nearlink_sdr.phy.usrp.USRPConfig[source]¶

USRP deviceconfigurationparameter。

Attributes: device_args: UHD device addressparameter, 空字符串表示自动发现。 channel_num: SLE 射频channel号。 band: 频段标识 (“2400” / “5100” / “5800”)。 sample_rate_hz: 采样率 (Hz)。 rx_gain_db: receive增益 (dB)。 tx_gain_db: 发射增益 (dB)。 bandwidth_hz: 前端模拟滤波器bandwidth (Hz), 0 表示不设置。 rx_antenna: receive天线端口名称。 tx_antenna: 发射天线端口名称。 clock_source: 参考时钟源。 time_source: PPS time源。 cpu_format: 主机端样本格式。 wire_format: 线缆端样本格式。 num_recv_frames: receivebufferframe数, 增大可减少溢出。 stream_timeout_s: 流操作timeouttime (秒)。
