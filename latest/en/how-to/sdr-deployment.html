SDR E310 Migration Plan¶

Prerequisites¶

  1. USRP E310 hardware ready, UHD driver installed

  2. Host machine connected to E310 over the network (or running directly on E310 ARM)

  3. SLE 2.4 GHz band RF calibration complete

Software Simulation Verification (Complete)¶

The following steps have been verified via MockUSRP loopback simulation:

  • IQ-level loopback: TX IQ samples → LoopbackBuffer → RX, AWGN/multipath channel optional

  • PHY full chain: encode → modulate → MockUSRP TX → channel → MockUSRP RX → demodulate → decode

  • MAC frame level: AsyncDataFrame pack → PHY → loopback → PHY → unpack

  • Hopping sequence: transmit/receive sequentially across multiple channels

  • Dual node: SleNode G + SleNode T end-to-end communication

  • Batch frames: multi-frame BER/FER statistics

Verification code: sim/usrp_sim.py + tests/test_usrp_sim.py (33 tests)

Stage 1: Hardware Verification¶

Goal: Verify the basic functionality of phy/usrp.py on real hardware

scripts/hw_verify.py:
  1. 初始化 USRPDevice(use_mock=False)
  2. 验证频率设置 (2402-2480 MHz)
  3. 验证增益控制 (TX/RX)
  4. 发射单载波 → 频谱仪确认
  5. 回环测试 (TX→RX, 外部衰减器/线缆)

Key parameters:

  • Sample rate: 1 MHz (GFSK) or 2 MHz (QPSK)

  • Center frequency: 2440 MHz (channel 19)

  • TX gain: 20 dB (initial low power)

  • RX gain: 40 dB

Stage 2: Physical Layer Loopback¶

Goal: TX pipeline → air/cable → RX pipeline loopback verification

scripts/phy_loopback.py:
  1. 构造 FT2 帧 (GFSK, MCS=0)
  2. mac_to_iq() 生成 IQ 样本
  3. SLETransceiver.transmit_iq() 发射
  4. SLETransceiver.receive_iq() 接收
  5. iq_to_mac() 解码比较
  6. 统计 BER/PER

Notes:

  • Use cable loopback + attenuator first to eliminate over-the-air interference

  • Frequency offset calibration: E310 TCXO accuracy ±2.5 ppm, corresponding to ±6 kHz@2.4 GHz

  • AGC: initial fixed gain, then add automatic gain control

Stage 3: Two-Device Communication¶

Goal: Transmit/receive communication between two E310 units

scripts/tx_node.py:    # G 节点发射端 (待创建)
scripts/rx_node.py:    # T 节点接收端 (待创建)

流程:
  G 节点:
    1. 广播帧发射 (周期性)
    2. 等待接入请求
    3. 建立连接
    4. 数据帧发射

  T 节点:
    1. 扫描广播帧
    2. 前导码检测 + 同步
    3. 解码广播帧
    4. 发送接入请求
    5. 数据帧接收

Stage 4: Protocol Stack Integration¶

Goal: Full protocol stack operation driven by the MAC state machine

main.py (重构):
  - CLI 入口: tx/rx/loopback/sim 模式选择
  - G 节点模式: 广播 → 接入 → 连接 → 数据传输
  - T 节点模式: 扫描 → 接入 → 连接 → 数据接收
  - 仿真模式: 各 Phase 仿真

关键集成:
  LinkManager → mac_to_iq() → SLETransceiver → 空口 → iq_to_mac() → LinkManager

Stage 5: Performance Optimization¶

  • Real-time performance: NumPy computation profiling, bottleneck identification

  • Buffer management: TX/RX buffer size tuning

  • Hopping latency: tune_channel() switch time measurement

  • Power control: dynamic TX gain adjustment

  • Clock synchronization: PPS/GPS external reference clock (optional)
