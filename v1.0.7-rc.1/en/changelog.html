Changelog¶

All notable changes to this project are recorded in this file.

Format based on Keep a Changelog, versioning follows Semantic Versioning.

[1.0.7-rc.1] - 2026-03-24¶

Fixed¶

  • PDF Mermaid diagrams: added pdfcrop to trim whitespace, eliminated full-page margins

  • PDF code block font: switched to DejaVu Sans Mono, fixed missing box-drawing characters

  • PDF special characters: replaced unsupported characters with text alternatives

Changed¶

  • Release CI: added semver tag validation, non-compliant tags fail the build

  • Release CI: prerelease tags automatically marked as GitHub Pre-release

  • AGENTS.md: added version/release standards and documentation build standards sections

[1.0.6] - 2026-03-23¶

Fixed¶

  • PDF code block overflow: enabled Sphinx verbatimforcewraps, severe overflows (>=100pt) reduced from 3426 to 0

  • PDF table overflow: sed post-processing of longtable column format, no severe overflows in either language

  • English PDF build: explicit xeCJK loading, margins expanded to 1.5cm

  • Release CI: fixed artifact paths, excluded .doctrees cache from HTML packages

Changed¶

  • Release CI: build and upload bilingual PDF + HTML documentation archives

  • Makefile: added docs-pdf-en target

[1.0.0] - 2026-03-21¶

Added¶

  • Protocol documentation series (docs/explanation/)

    • overview.md: SparkLink SLE protocol overview, positioning, stack structure, core concepts

    • physical-layer.md: physical layer details, modulation/frame structure/channel coding/TX-RX Pipeline

    • mac-layer.md: MAC layer details, broadcast/access/link management/signaling/QoS/scheduling

    • security.md: security subsystem details, pairing/key derivation/frame encryption/privacy/UWB security

    • data-flow.md: end-to-end data flow, complete processing chain from application to air interface

    • Updated docs/index.md toctree, organizing documents from shallow to deep

Fixed¶

  • GFSK modulator: added mod_index [0.45, 0.55] range validation (§6.2.1.1)

  • Broadcast manager: added broadcast interval [4ms, 2097.151875s] range validation (§7.1.1)

  • Broadcast manager: added [0, 2ms] random delay calculation method (§7.1.1)

  • Rust acceleration module (rust/nearlink_sdr_accel)

    • Polar SC decoder Rust implementation built with PyO3 + maturin

    • SSC optimization (rate-0/rate-1 subtree pruning) + scalar f/g operations

    • Python side auto-detection, falls back to pure Python implementation when unavailable

    • Pipeline decode performance improved >10x, overall pipeline speedup 2.2x (389ms → 174ms)

    • Test suite reduced from 9.48s to 5.12s

    • Rust Polar encoder (butterfly GF(2) transform), pipeline speedup 3.9x (389ms → 101ms)

    • Overall test suite reduced from 12.36s to 4.10s

    • Rust CRC computation (bit-level shift register), eliminates Python loop overhead

    • Rust m-sequence generation (popcount feedback optimization), eliminates Python loop overhead

    • Pipeline single call 1.36ms (pure Python baseline 389ms, speedup ~280x)

  • Rust acceleration installation tool (scripts/install_accel.py)

    • Auto-detects Rust toolchain, installs maturin, compiles acceleration module

    • Compatible with both uv and pip package management

    • Silently falls back on installation failure, does not affect project operation

  • Rust quality toolchain

    • Core logic extracted as pure Rust functions, verifiable directly with cargo test

    • 20 native Rust tests (CRC/m-sequence/Polar coding/SC decoding)

    • clippy lint (deny warnings) + rustfmt formatting

    • CI added rust job: fmt + clippy + cargo test

  • CI integrated Rust acceleration build

    • test/coverage/examples three jobs integrate dtolnay/rust-toolchain@stable + maturin

    • Added install-accel job: verifies install_accel.py script and acceleration module loading

    • Fixed maturin using wrong venv in CI subdirectory (--manifest-path replaces cd rust)

  • Rust acceleration how-to guide (docs/how-to/rust-acceleration.md)

    • Installation methods (automatic/manual), verification, performance comparison, troubleshooting

  • Simulation output directory management

    • All simulation plots output to output/ directory

    • Environment variable NEARLINK_SDR_OUTPUT for custom output path

    • 16 historical PNG files in root directory removed from git tracking

  • GitHub Actions CI workflow (.github/workflows/ci.yml)

    • Dark/light mode adaptive

  • Phase 16: multi-user interference + Doppler time-varying channel simulation (25 test cases)

    • Jakes sum-of-sinusoids model: replaces original independent Rayleigh, generates time-correlated fading with J₀ autocorrelation

    • Multi-user interference model: InterferenceConfig / add_interference() / compute_sinr()

Changed¶

  • Performance optimization: test suite reduced from 12.36s to 9.48s (23% reduction)

    • Phase 16 simulation function run_phase16_simulation() and example doppler_interference() parameterized n_frames

    • Tests use n_frames=5 instead of default 50, greatly reducing simulation time while verifying correctness

    • Profiling conclusion: Polar SC decoder accounts for 45% of pipeline time; pure Python has reached optimization limits. Recursion/iteration/scalar fast-path schemes show no significant improvement; further acceleration requires Cython/Numba compilation.

  • Documentation code examples refactored: from inline markdown Python to standalone example projects

    • tests/test_doc_examples.py rewritten as example project persistence tests (34 test cases)
